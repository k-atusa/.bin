====================
femto C 기본 목적 : C 수준의 유연한 저수준 제어에 rust의 소유권 개념을 부분적으로 결합시킨 언어, 단순함과 통일성 지향.

타입 시스템 :
  원시 타입 :
    고정크기 정수 : u8, u16, u32, u64, i8, i16, i32, i64
    플랫폼 의존크기 정수 : uint, int
    실수 : f32, f64
    불리언 : bool
  타입 전치사 :
    포인터 : 소유권 box T, 가변참조 &T, 불변참조 &const T, 원시 *T
    nullable : ?box T, ?&T, ?&const T는 void(NULL 대신 void 사용)일 수 있음.
    배열 : []T는 *T와 동일하며 여러 T가 연속된 메모리 구조를 나타냄.
  기타 포인터 : 원형 포인터 *void, 함수 포인터 (func (...): T)
  캐스팅 : (id as T)

소유권 시스템 :
  box T는 항상 유효한 힙 인스턴스 T를 참조.
  scope : 중괄호 {}로 표현, scope가 끝나면 자동으로 소멸자가 호출.
  변수 대입과 함수 인자 전달 시 소유권 이동, 유효성을 컴파일러가 검증.
  &T는 유효한 인스턴스 T에 대한 참조이며 읽기쓰기 모두 가능 (&const T는 읽기전용 참조).
  한번에 여러 &const T 혹은 하나의 &T만 존재 가능.
  배열 인덱싱과 전역변수 접근 멀티스레딩 안전성은 C와 동일하게 동작 (별도의 컨테이너 객체나 lock을 사용해야 함).

원시 포인터 기능 :
  malloc, free, sizeof로 직접 *T를 다룸.
  원시 포인터와 관리 포인터 변환규칙 :
    box T, &T, &const T -> *T : 명시적인 캐스팅 필요, 소유권은 여전히 T에 존재, (free(*T)는 오류).
    *T -> &T, &const T : 원시 포인터 값에 대한 일시적 빌림 (빌리는 중 free 사용은 오류).
    *T -> box T : 명시적인 소유권 이동, 이후 *T에 대한 free 사용은 오류.
  unsafe function :
    함수명이 _로 끝남 (id_).
    unsafe function 내부에만 가능한 동작 :
      malloc, free, *T 산술연산, *T 역참조
      *T에서 box T, &T, &const T로의 캐스팅

변수 선언 :
  var id: type;
  var id: type = expr;
  var id = expr; (타입 추론)
  const id: type = expr;
  상수, box T, &T, &const T는 선언과 함께 초기화되어야 한다.
  리터럴로 초기화된 원시 타입 상수는 컴파일 타임 리터럴로 취급한다.
  box T에 새 값을 할당하면 기존 값은 자동으로 delete 된다.

배열 선언 :
  배열의 이름도 타입은 포인터와 완전히 동일하다.
  var id: [cons expr]T; (타입은 *T)
  var id: [constexpr][constexpr]T = {...};

동적 메모리 선언 :
  new는 힙 메모리를 확보하고 항상 box 타입만을 반환한다.
  var id: box T = new T;
  var id: box T = new T(...);
  var id: box T = new [expr]T; (box도 내부적으로는 포인터라 동적배열도 일반 인스턴스와 같은 타입이다.)

배열과 동적 메모리 인덱싱 :
  인덱싱 : id[expr], 항목에 대한 직접 접근.
  내부적으로는 *(id + expr)과 동일하다.

연산자 :
  산술 : + - * / %
  관계 : < <= > >= == !=
  논리 : && || !
  비트 : & | ~ ^ << >>
  메모리 :
    역참조 *
    참조 &
  캐스팅 : as

제어문 :
  if (bool) scope, if (bool) scope else scope, if (bool) scope else if (bool) scope
  switch (integer expr) { case integer constexpr: ... case a, b: ... default: ... }
  while (bool) scope
  for (st; bool expr; st) scope
  흐름 제어 : break, continue

함수 :
  id가 언더바 (_)로 시작하는 함수만 private 하다.
  func id() {}
  func id(a: type, b: type): type {}
  func id(parms): T scope
  return expr;

구조체 :
  id가 언더바 (_)로 시작하는 구조체 혹은 필드만 private 하다.
  필드, 메서드 접근은 . 사용, 구조체 포인터는 자동 역참조.
  struct T { id: type; id: type; }
  생성자와 소멸자, box T 복사는 특수 이름 __new, __delete, __copy 메서드 사용 가능 :
    func (self: box T) __new(...): box T {...}
    func (self: box T) __delete(...) {...}
    func (self: &T) __copy(...): box T {...}
  구조체 메서드 :
    func (self: *T) id(...) {...}
    func (self: &T) id(...) {...}
    func (self: &const T) id(...) {...}

열거형 :
  id가 언더바 (_)로 시작하는 열거형만 private 하다.
  열거형은 컴파일 시 정수형으로 변환되며, id를 타입처럼 사용할 수 있다.
  enum E: T {id, id, id...} (T는 원시 타입 정수형만 가능)
  var id: E = id;처럼 사용.

예외 처리 :
  일반적인 예외는 오류코드 반환으로 처리.
  심각한 오류는 try, catch, raise (box T만 던지기 가능)로 처리.
  try { raise id; } catch (var e: box T) {...}
  예외 객체 err.e {code: int; msg: box u8}는 표준 라이브러리에서 제공 예정.
  raise 없는 기본 예외(new 메모리 확보 실패 등)은 box int 타입의 에러 발생.

모듈 :
  파일명이 모듈 name.
  #include "name"; (로컬 파일 코드)
  #include <name>; (전역 저장소 코드)
  #include "name" as "alias";
  표준 라이브러리 : std
  C 표준 라이브러리 : c.xxx

컴파일러 직접 지시 :
  주석 : //, /* */
  #order 사용 :
    #raw_asm {...}
    #raw_llvm {...}
    #raw_c {...}
    #template <T, E>
